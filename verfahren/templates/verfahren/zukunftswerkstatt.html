{% translate "Die Zukunftswerkstatt" %}

{% blocktranslate %}Was würde Ihr Antrag im Staat bewegen? Die Zukunftswerkstatt beantwortet das — mit der StaatsSimulation als Rechenkern, einem digitalen Zwilling des Staatswesens in wachsender Auflösung: Für jeden Antrag schätzt sie ab, welche Gesetze er berührt, was seine Umsetzung für Verwaltung und Personal bedeutet und wie lange sie realistisch dauert — mit amtlichen Quellen belegt, für alle lesbar. Und sie lernt: aus jedem Vergleich von Prognose und Wirklichkeit.{% endblocktranslate %}

{% translate "Zwei Gesichter, ein Werkzeug" %}

{% translate "Nach außen" %}

{% translate "Politische Bildung durch Selbermachen" %}

{% blocktranslate %}Wer einen Antrag einbringt, sieht seine Folgen: berührte Gesetze mit Links ins Rechtsinformationssystem des Bundes, Aufwand für den Staatsapparat, Ausschreibungspflichten, realistische Dauer. Jede Einschätzung ist zitierfähig — für Schulen, Presse und alle Interessierten, ganz ohne Mitgliedschaft.{% endblocktranslate %}

{% translate "Nach innen" %}

{% translate "Das Sinnesorgan der Selbstregulation" %}

{% blocktranslate %}Vor jeder Entscheidung eine Prognose, nach jeder Umsetzung die Wirklichkeit — und aus der Differenz lernt die Plattform, unter Aufsicht des Koordinationsrats. Verfahren, Fristen und Schwellen werden zu messbaren Stellgrößen, die sich auf Grundlage erkannter Muster behutsam anpassen lassen — beschlossen immer von Menschen.{% endblocktranslate %}

{% translate "Vier Grundsätze" %}

{% translate "Die KI schlägt vor, sie entscheidet nie." %}

{% blocktranslate %}Jede Ausgabe der Simulation ist als Einschätzung gekennzeichnet, mit Quellen und Kontextstand. Automatisierte Systeme bewerten, priorisieren oder verwerfen keine Anträge — das verbietet die Satzung (§ 2 Abs 6). Entscheidungen treffen Menschen.{% endblocktranslate %}

{% translate "Der Demos darf atmen, die Stimme wiegt immer gleich." %}

{% blocktranslate %}Wer zum Kreis der Entscheidenden gehört — Gemeinde, Land, Bund —, darf sich je nach Betroffenheit unterscheiden und über die Jahre dazulernen. Das Gewicht einer Stimme innerhalb des Kreises ist unantastbar: keine Qualifikations-, Bildungs- oder Verdienstgewichtung, nirgends.{% endblocktranslate %}

{% translate "Das Gedächtnis ist der Schatz, nicht das Modell." %}

{% blocktranslate %}KI-Modelle sind austauschbar. Unersetzlich ist das öffentliche Archiv aus Prognose und Ausgang: Ein Prognose-Register hält jede Einschätzung gegen die spätere Wirklichkeit — wir veröffentlichen unsere eigenen Fehlprognosen und werden daran messbar besser.{% endblocktranslate %}

{% translate "Auf Unwissen gebaut." %}

{% blocktranslate %}Niemand weiß heute, welche Fragen die nächsten Jahrzehnte stellen. Deshalb sind alle Stellgrößen Parameter in einem öffentlichen Register, Regeländerungen laufen als dokumentierte Experimente mit Messgröße und Rückweg — eine lernende Verfassung ohne Beliebigkeit.{% endblocktranslate %}

{% translate "Der Weg eines Antrags im Zielbild" %}

  1. {% blocktranslate %}Einbringen. Die Simulation prüft sofort auf ähnliche Anträge — wer mag, unterstützt einen bestehenden (und erbt dessen Ergebnisse) oder stellt den eigenen.{% endblocktranslate %}
  2. {% blocktranslate %}Unterstützung. Erreicht der Antrag die Schwelle — selbst ein lernbarer Parameter —, geht er in die Beratung.{% endblocktranslate %}
  3. {% blocktranslate %}Beratung. Die StaatsSimulation — der Rechenkern der Zukunftswerkstatt — rechnet durch (Rechtsfolgen, Aufwand, Lastampel, Vergabe), der Expertenrat erarbeitet auf dieser Grundlage seine Vorlage — Fachleute aus öffentlicher Liste, per offengelegtem Zufallsverfahren ausgewählt, Stellungnahmen im Wortlaut veröffentlicht.{% endblocktranslate %}
  4. {% blocktranslate %}Vorlage an die Unterstützer. Die Vorlage geht zuerst an jene, die den Antrag getragen haben: nachbessern lassen oder weiterreichen — so bleibt sie dem Anliegen treu.{% endblocktranslate %}
  5. {% blocktranslate %}Endabstimmung. Alle Stimmberechtigten entscheiden; Vorlage, Stellungnahmen und Durchrechnung liegen jedem Stimmzettel bei. Kein Organ kann durch Untätigkeit blockieren.{% endblocktranslate %}
  6. {% blocktranslate %}Umsetzung und Lernen. Das öffentliche Umsetzungsregister zeigt, was aus dem Beschluss wird — und das Prognose-Register vergleicht die Einschätzung mit der Wirklichkeit. Der Kreis schließt sich.{% endblocktranslate %}

{% blocktranslate %}Die Schritte 1 bis 3 und 5 bis 6 entsprechen dem Satzungsentwurf 2.3; die Unterstützer-Schleife in Schritt 4 ist Zielbild und erhält vor Einführung einen eigenen Satzungsbaustein.{% endblocktranslate %}

{% translate "Woher die Fakten kommen" %}

{% blocktranslate %}Die Simulation arbeitet auf einer kuratierten, versionierten Faktenbasis aus amtlichen und offenen Quellen: dem Rechtsinformationssystem des Bundes (alle Gesetze samt Fassungen), den amtlichen Personal-Aggregaten des Bundes (nie personenbezogene Listen), den offenen Kerndaten öffentlicher Vergaben — und dem, was die Plattform selbst weiß: Anträge, Beschlüsse, Umsetzungsstände. Kein KI-System schreibt je in diese Faktenbasis; jede Einschätzung nennt den Stand, mit dem sie entstand, und ist dadurch überprüfbar und anfechtbar. Wo Daten fehlen — etwa echte Firmenkapazitäten —, sagen wir das offen, statt Näherungen als Wissen auszugeben.{% endblocktranslate %}

{% translate "Wer wacht worüber" %}

{% blocktranslate %}Der Koordinationsrat beaufsichtigt Faktenbasis und Parameterregister und empfängt die Berichte der Simulation. Die Hervorhebung eines Antrags bleibt allein beim Integritätsrat — durch veröffentlichten, begründeten Beschluss, niemals durch einen Algorithmus (§ 5 Abs 10). Der Expertenrat arbeitet in zwei unabhängigen Gruppen: Die zweite prüft bei direkten Aufgaben die Vorschläge der ersten auf Interessenkonflikte und kann sie begründet zurückgeben. Und jedes Mitglied kann jede Einschätzung öffentlich beanstanden — die Antwort ist ein Korrekturlauf mit Vermerk, nie ein stilles Ändern.{% endblocktranslate %}

{% translate "Der Modell-Steckplatz — Rechenschaft in Zahlen" %}

{% blocktranslate %}Jeder KI-Aufruf der Plattform läuft über einen anbieterneutralen Steckplatz und hinterlässt einen archivierten Lauf: Zweck, Modell, Tokenverbrauch, Dauer — auch der gescheiterte. Ein hartes Monats-Tokenbudget deckelt die Kosten; ist es erschöpft, wird der Steckplatz stumm. Und immer gilt: Die KI schlägt vor, sie entscheidet nie.{% endblocktranslate %}

{% translate "An die demokratischen Bewegungen weltweit" %}

{% blocktranslate %}Auf mehreren Kontinenten arbeiten Parteien und Bewegungen an derselben Idee: Die Bürgerinnen und Bürger entscheiden selbst, die Technik ist das Werkzeug. Jedes Land wird sein eigenes lernendes System bauen, zugeschnitten auf seine Menschen und seine Rechtsordnung — aber die Parameter, an denen Demokratien lernen (Schwellen, Fristen, Beteiligung, Revisionsraten, Prognosegüte), sprechen überall dieselbe Sprache. Wir laden dazu ein, sie gemeinsam zu erheben und zu vergleichen: ein Labor der Demokratien, auf Jahrzehnte angelegt.{% endblocktranslate %}
