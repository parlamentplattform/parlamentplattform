{% translate "Wir haben kein Parteiprogramm, das wir abgleichen müssten. Wir haben eine Vision, die wir gemeinsam konkretisieren." %}

{% blocktranslate trimmed %} Die Bürgerinnen und Bürger entscheiden selbst. Eine Partei dieser Art trägt keine Meinungen, sie ist das Werkzeug, mit dem eine Gesellschaft ihre Entscheidungen selbst trifft, nachvollzieht und umsetzt — die logisch nächste Form der gesamtgesellschaftlichen Selbstorganisation. {% endblocktranslate %}

{% blocktranslate trimmed %} Nachrechenbar statt vertrauensbedürftig. Jedes Verfahren kann jeder Mensch ohne Spezialwissen nachrechnen; Regeln frieren beim Einbringen ein; nichts wird verdeckt gereiht; nichts, was ein Verfahren betrifft, wird gelöscht. Betroffene und Fachkundige zuerst. Die Technik schlägt vor, sie entscheidet nie. Mandatare setzen um — gebunden, offen berichtend, von den Mitgliedern gesteuert. {% endblocktranslate %}

{% blocktranslate trimmed %} Ein Kern, viele Instanzen. Jedes Land betreibt dieselbe Grundsoftware auf eigenen Servern, unter eigener Satzung, in eigener Sprache — und lernt dort selbst. Den Kern entwickeln wir gemeinsam weiter, mit regelmäßigem Austausch und Abgleich. Parameter werden gemeinsam eingeführt, ihre Werte bleiben jedem Land eigen. Angleichen statt abgleichen: Weil wir keine Programme haben, gibt es nichts zu verhandeln außer der Vision selbst — Fassung für Fassung, im Plattform-Rat mit einer Stimme je Land. Verbunden durch Werkzeug, Schema und Vision, nicht durch Geld. {% endblocktranslate %}

{% translate "Ein Kern, viele Instanzen" %}

{% blocktranslate trimmed %} Kern und Instanzen. Der gemeinsame Kern ist das Repository der ParlamentPlattform: Quellcode, versionierte Freigaben, das Schema. Jedes Land betreibt daraus seine eigene Instanz — eigene Datenbank auf eigenen Servern, eigenes Parameterregister, eigener Kategorienbaum, eigene Satzung. Landesspezifisches liegt in Konfiguration und Daten, nicht im Code. {% endblocktranslate %}

{% blocktranslate trimmed %} Abgleich. Vierteljährlich gibt der Kern eine Freigabe; die Instanzen ziehen sie nach. Erweiterungen eines Landes kommen in den Kern, wenn sie sich parametrisieren lassen — sonst bleiben sie dokumentiertes Modul der Instanz. Ein Plattform-Rat mit einer Person je Land beschließt die Freigaben; das Protokoll ist öffentlich. {% endblocktranslate %}

{% blocktranslate trimmed %} Parameter gemeinsam, Wirkung eigen. Neue Stellgrößen entstehen im Kern mit einer sprachneutralen Kennung und einer Empfehlung. Ihren Wert setzt jede Instanz selbst und lernt ihn in ihrem Register weiter — so wirkt derselbe Parameter in jedem Land auf dessen eigene Weise. {% endblocktranslate %}

{% blocktranslate trimmed %} Lernfortschritt. Was ein Land über Fristen, Schwellen oder Beteiligung lernt, wird über die Schnittstelle vergleichbar — aggregiert, nie personenbezogen. Verglichen wird, übernommen nur durch Beschluss der eigenen Mitgliederversammlung. {% endblocktranslate %}

{% translate "Die Schnittstelle" %}

{% blocktranslate trimmed %} Getauscht wird nur, was überall dasselbe bedeutet: Stellgrößen mit sprachneutralen Kennungen und aggregierte Kennzahlen. Werte bleiben jedem Land eigen; personenbezogene Daten verlassen eine Instanz nie. Alle Adressen sind öffentlich, ohne Anmeldung. Schema-Version 1.0. {% endblocktranslate %}

{% translate "Der Fahrplan der Zusammenarbeit" %}

{% translate "1 · Software bereitstellen und gemeinsam einrichten" %}
{% blocktranslate %}Die ParlamentPlattform ist vollständig quelloffen (AGPL), zweisprachig und dokumentiert — inklusive nachrechenbarer Auszählung, manipulationssicherem Audit-Log, Gremien-Werkstatt und Parameterregister. Wir helfen beim Aufsetzen und bei der Anpassung an euer Land.{% endblocktranslate %}
{% translate "2 · Gemeinsame Standards und Werkzeuge" %}
{% blocktranslate %}Ein offener Standard „Nachrechenbare Abstimmung" (Exportformat plus unabhängige Prüfwerkzeuge), Werkzeugtausch unter freien Lizenzen und ein gemeinsames Schema für Beteiligungskennzahlen — ehrlicher Vergleich statt Marketingzahlen.{% endblocktranslate %}
{% translate "3 · Lernfortschritt und Parameter gemeinsam erheben" %}
{% blocktranslate %}Das Parameterregister trägt sprachneutrale Schema-Kennungen: Was Österreich über Fristen lernt und andere über Delegation oder Schwellen, wird strukturiert getauscht — ein ständiger Austausch der Plattform-Verantwortlichen, auf Jahrzehnte angelegt.{% endblocktranslate %}

{% translate "Was wir mitbringen — und was wir suchen" %}

{% blocktranslate %}Wir bringen mit: die nachrechenbare Auszählung ohne Vertrauensbedarf, das Regel-Einfrieren (laufende Verfahren behalten ihre Regeln), die Bindung mit Rückkanal (Umsetzungsregister und Vollzugsrückmeldung), Selbstregulation ohne Antragsverfall — Satzung und Software aus einem Guss.{% endblocktranslate %}

{% blocktranslate %}Wir suchen: Betriebspraxis gebundener Mandate, Kampagnen- und Reichweitenerfahrung, Breitenhörungs-Werkzeuge und eID-Praxis — die Stärken derer, die schon Wahlen gewonnen oder Jahrzehnte Regelpraxis gesammelt haben.{% endblocktranslate %}

{% translate "Sprechen wir." %} {% blocktranslate %}Kurz und konkret — mit einem Angebot und einer Lernfrage. Arbeitssprache Englisch oder Deutsch.{% endblocktranslate %}
