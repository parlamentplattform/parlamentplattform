{% translate "Vom Antrag zum Beschluss" %}

1
{% translate "Einbringen" %}

{% blocktranslate %}Sie schreiben Ihren Vorschlag — die Plattform zeigt sofort ähnliche Anträge: unterstützen oder selbst einbringen, Ihre Wahl.{% endblocktranslate %}

2
{% translate "Unterstützung sammeln" %}

{% blocktranslate %}Erreicht der Antrag die veröffentlichte Schwelle, geht er weiter — sonst bleibt er offen einsehbar, nichts verschwindet.{% endblocktranslate %}

3
{% translate "Beratung" %}

{% blocktranslate %}Mindestens 21 Tage öffentliche Erörterung. Die Zukunftswerkstatt rechnet durch, welche Gesetze berührt wären und was die Umsetzung kosten würde; der Expertenrat gibt seine Stellungnahme im Wortlaut ab.{% endblocktranslate %}

4
{% translate "Abstimmung" %}

{% blocktranslate %}Alle Stimmberechtigten entscheiden — mit allen Unterlagen am Stimmzettel. Eine Person, eine Stimme.{% endblocktranslate %}

5
{% translate "Ergebnis — nachrechenbar" %}

{% blocktranslate %}Ergebnis, Beteiligung und aggregierte Rohdaten werden veröffentlicht; jede und jeder kann die Auszählung unabhängig wiederholen.{% endblocktranslate %}

6
{% translate "Umsetzung" %}

{% blocktranslate %}Angenommene Anträge wandern ins öffentliche Umsetzungsregister: Stand, Hindernisse und Fortschritt — bis der Beschluss Wirklichkeit ist. Als Partei setzen unsere Mandatare um, was Sie beschließen.{% endblocktranslate %}

{% translate "Die Mitgliedschaft im Detail" %}

{% translate "Anwartschaft" %}

{% translate "Mitentscheiden mit Anlauf" %}

{% blocktranslate %}Nach der Satzung sind Sie bei Sachfragen nach drei Monaten stimmberechtigt, bei Personal- und Satzungsfragen nach zwölf — ein Schutz gegen feindliche Übernahmen. In der Aufbauphase gilt die Übergangsregel: Die Fristen entfallen, bis die Mitglieder die erste Verfahrensordnung beschlossen haben.{% endblocktranslate %}

{% translate "Beitrag" %}

{% translate "Selbsteinschätzung statt Tarif" %}

{% blocktranslate %}Richtwert 30 € im Jahr — die Höhe bestimmen Sie selbst, und niemand wird aus finanziellen Gründen ausgeschlossen. Bezahlt wird per QR-Code direkt von Konto zu Konto, ohne Zahlungsdienstleister.{% endblocktranslate %}

{% translate "Identität" %}

{% translate "Ein Mensch, eine Stimme — pseudonym nach außen" %}

{% blocktranslate %}Ein Konto je Person, mit geprüfter Identität — das schützt vor gekauften Mehrheiten. Öffentlich treten Sie unter einem beständigen Pseudonym auf, wenn Sie möchten; Ihre Stimme bleibt bei Abstimmungen pseudonym.{% endblocktranslate %}

{% translate "Ihre Region" %}

{% translate "Gemeinde, Land, Bund" %}

{% blocktranslate %}Regionale Anträge entscheidet, wen sie betreffen: Ihre Gemeinde stimmt über Gemeindesachen ab, Ihr Land über Landessachen. Ihre Lebensbereiche wählen Sie als Favoriten — Neues daraus erscheint direkt in Ihrem Parlament.{% endblocktranslate %}
