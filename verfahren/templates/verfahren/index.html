{% translate "So funktioniert das System" %}

{% translate "Der Weg jedes Antrags — festgelegt in einer offenen Verfahrensordnung, deren Regeln jede Antragsseite mitliefert." %}

{% translate "Einbringen" %}

{% blocktranslate %}Jedes Mitglied kann einen Antrag stellen — für den Bund, das Land, den Bezirk oder die Gemeinde des eigenen Wohnsitzes. Ein Hinweis auf ähnliche Anträge hilft, Kräfte zu bündeln statt zu zersplittern.{% endblocktranslate %}

{% translate "Unterstützen" %}

{% blocktranslate %}Der Antrag sammelt öffentliche Unterstützungen. Erreicht er die Schwelle der Verfahrensordnung innerhalb der Frist, geht er weiter — sonst verfällt er, ehrlich dokumentiert.{% endblocktranslate %}

{% translate "Beraten" %}

{% blocktranslate %}Alle Mitglieder beraten offen mit. Der Expertenrat kann in seiner Werkstatt einen Vorschlag erarbeiten — Fassung für Fassung dokumentiert; die Unterstützer des Antrags nehmen ihn an oder geben ihn mit konkreten Wünschen zurück (Entwurfsschleife). Niemand kann dabei blockieren: Verstreichen Fristen, geht es automatisch weiter.{% endblocktranslate %}

{% translate "Abstimmen" %}

{% blocktranslate %}Abgestimmt wird geheim über ein Stimmregister mit Pseudonymen: Jede Stimme ist veröffentlicht und zählbar, aber keinem Menschen zuzuordnen. Zwischenstände bleiben bis zum Fristende verdeckt — niemand soll der Mehrheit hinterherlaufen.{% endblocktranslate %}

{% translate "Nachrechnen und umsetzen" %}

{% blocktranslate %}Nach Fristende zählt die Plattform aus — und jeder kann das Ergebnis mit dem offenen Datenexport unabhängig nachrechnen. Beschlüsse wandern ins Umsetzungsregister; die Mandatare zeigen öffentlich, was sie daraus machen.{% endblocktranslate %}

{% translate "Die Wege durch die Plattform" %}

{% translate "Zwei Antragswege, eine Werkstatt-Schleife — jede Frist ist ein offener Parameter." %}
